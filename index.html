Start here — learn by doing

This lab is a step-by-step classroom as well as a real experiment. Everything we learn here is documented so another person can repeat it, understand the commands, check the sources and measure their own result.

Learning path

01
Understand mining
Learn what proof-of-work, hashes, algorithms, miners, pools and shares actually mean. Read the Monero mining documentation →
02
Choose your hardware
Phone, tablet, laptop or desktop. First identify the CPU/GPU and what algorithms it can run.
03
Choose an algorithm
For our Monero experiment we use RandomX, a proof-of-work algorithm designed to favor general-purpose hardware. Learn about Monero mining →
04
Create a wallet
Use a wallet you control. Your recovery seed and private keys are never entered into this website or shared with anyone. Official Monero downloads →
05
Install the tools
Android users can use Termux for a terminal environment. Install from a trusted official source and do not mix Termux builds from different sources. Termux documentation →
06
Connect to a pool
A pool coordinates miners and records submitted shares. Always read the pool's own instructions before connecting. XMRPool beginner guide →
07
Start the experiment
Run the miner, watch the output and learn what every number means. Never paste a seed phrase or private key into a command.
08
Measure it
Record hashrate, accepted/rejected shares, temperature, runtime and electricity consumption.
09
Calculate the economics
Put your measured hashrate, power and electricity price into the calculator below.
10
Compare and publish
Compare your result with other devices and contribute evidence to the CICAN benchmark database.

Example: our RandomX test

Pixel 6 · 8 threads · RandomX · XMRPool TLS primo-arm-miner -a randomx -o stratum+ssl://xmrpool.eu:3333 -u YOUR_WALLET_ADDRESS -p x -t 8 Replace YOUR_WALLET_ADDRESS with your own receiving address. Never paste a seed phrase or private key.

How to improve the result

1. Test thread counts.
More threads do not always mean better efficiency. Compare performance at different settings.
2. Control heat.
Thermal throttling can reduce sustained hashrate. Cooling and airflow matter.
3. Measure electricity.
Battery readings are not the same as wall power. Use a USB-C power meter for proper input measurements.
4. Compare devices.
Hashrate alone is not enough. Compare hashrate per watt and estimated earnings per day.
5. Separate benchmark from real mining.
A local benchmark proves what hardware can calculate. Pool mining shows whether the complete setup actually works.

Safety & verification

Never share your recovery seed or private keys.
Download wallets and mining software from trusted sources, verify releases when possible, and treat unexpected scripts or commands as untrusted until you understand them.

What CICAN is building

A public, evidence-first benchmark of real devices — phones, tablets, laptops, desktops and other hardware — showing what they can mine, how fast they are, how much energy they use and whether the economics make sense.

Roadmap

Learn → reproduce → benchmark → measure energy → calculate profitability → compare hardware → build the public CICAN benchmark database.
